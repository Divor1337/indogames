# Drop Arcade — LATAM landing

Статическая мобильная прокладка на нейтральном латиноамериканском испанском (`es-419`). Подходит для аудитории Мексики, Чили и других испаноязычных стран.

## Что лежит в корне

- `index.html` — разметка и испанские тексты.
- `styles.css` — дизайн и адаптация для телефонов.
- `script.js` — ссылка, промокод, бонус, модальное окно и перенос UTM-меток.
- `game-1.gif` … `game-4.gif` — игровые GIF. Пути в HTML построены прямо из корня.
- `vercel.json` — настройки Vercel и кеширование GIF.

## Быстрая замена ссылки и оффера

Откройте верхнюю часть `script.js`:

```js
const CONFIG = {
  gameUrl: "https://lkmn.cc/6728",
  promoCode: "PIXEL4",
  bonus: "+500%"
};
```

`gameUrl` автоматически устанавливается для всех игровых карточек, главных кнопок и мобильной CTA. UTM-метки из адреса прокладки переносятся в конечную ссылку.

## Деплой

Загрузите содержимое папки в корень GitHub-репозитория и подключите его к Vercel с пресетом `Other`. Build Command и Output Directory оставьте пустыми.
