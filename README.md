# Falling Pickaxe — упрощённая прокладка

Статическая одностраничная версия на нейтральном латиноамериканском испанском.
Сборка не требуется: точка входа — `index.html`.

## Что находится на странице

- одна игра — Falling Pickaxe;
- одна внешняя кнопка `JUGAR AHORA`;
- анимация `game-1.mp4` с `game-1.gif` как запасным вариантом;
- бонус до `+500%`;
- промокод `PIXEL4` с кнопкой копирования;
- обязательные пометки `18+`, условия бонуса и ответственная игра;
- автоматический перенос разрешённых UTM и рекламных SubID-параметров в
  партнёрскую ссылку. Остальные параметры намеренно не передаются.

## Что менять

Ссылка, промокод и размер бонуса находятся в самом верху `script.js`:

```js
const CONFIG = {
  gameUrl: "https://lkmn.cc/6728",
  promoCode: "PIXEL4",
  bonus: "+500%"
};
```

В корне проекта должны лежать:

- `game-1.mp4` — облегчённая версия анимации для современных браузеров;
- `game-1.gif` — запасной вариант для браузеров без поддержки видео.

MP4 весит примерно в четыре раза меньше исходного GIF и визуально показывает
ту же самую игру.

SEO-описание страницы сделано универсальным и не содержит конкретного
промокода или размера бонуса, поэтому при изменении `CONFIG` оно не устаревает.

## Публикация на Vercel

1. Загрузите содержимое папки в корень GitHub-репозитория.
2. Подключите репозиторий в Vercel.
3. Framework Preset: `Other`.
4. Build Command и Output Directory оставьте пустыми.
5. Нажмите `Deploy`.

Файлы `game-2.gif`, `game-3.gif`, `game-4.gif` и папка `assets` новой страницей
не используются. Их можно оставить в репозитории или удалить перед загрузкой.
