# Korean Game Picks — статическая версия

Эту папку можно целиком загрузить в новый GitHub-репозиторий и подключить к Vercel. Сборка не требуется: точка входа — `index.html`.

## Состав проекта

- `index.html` — разметка витрины и инструкции.
- `styles.css` — весь дизайн и мобильная адаптация.
- `script.js` — ссылки, промокод, бонус, модальное окно и копирование кода.
- `assets/hero-pixel-art.png` — иллюстрация первого экрана.
- `assets/step-1.jpg` … `assets/step-4.jpg` — ваши скриншоты регистрации.
- `vercel.json` — минимальная настройка Vercel.

## Что менять

Все основные значения находятся в самом верху `script.js`:

```js
const CONFIG = {
  gameUrl: "https://lkmn.cc/6728",
  registerUrl: "https://lkmn.cc/357520",
  promoCode: "TOWER3",
  bonus: "+500%"
};
```

## Как добавить фотографии инструкции

Положите в папку `assets` четыре вертикальных или обычных скриншота и назовите их:

1. `step-1.jpg`
2. `step-2.jpg`
3. `step-3.jpg`
4. `step-4.jpg`

До добавления фотографий сайт показывает аккуратные заглушки с нужными именами файлов.

## Деплой на Vercel

1. Загрузите содержимое этой папки в корень GitHub-репозитория.
2. В Vercel выберите `Add New → Project` и подключите репозиторий.
3. Framework Preset оставьте `Other`.
4. Build Command и Output Directory оставьте пустыми.
5. Нажмите Deploy.
